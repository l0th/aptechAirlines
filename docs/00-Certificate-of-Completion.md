### THÔNG TIN CHI TIẾT ĐỒ ÁN
- **Tên đồ án (Project Title):** Airline Reservation System (Hệ thống Quản lý và Đặt vé Máy bay trực tuyến)
- **Tên thương hiệu ứng dụng:** Aptech Airlines Fullstack Web Application
- **Mã môn học / Khóa học:** eProject - HDSE (Higher Diploma in Software Engineering) / ADSE
- **Thời gian thực hiện:** Từ ngày `<Ngày bắt đầu>` đến ngày `<Ngày kết thúc>` (Thời lượng: 30 ngày)
- **Công nghệ chính sử dụng:**
  - **Backend API:** NestJS Framework (TypeScript), Mongoose ODM, JWT Authentication, Nodemailer, Node-cron Scheduler.
  - **Frontend Portal:** Angular 21 Standalone Components, Reactive Forms, Signals, Tailwind CSS v3, Lucide Angular Vector Icons.
  - **Cơ sở dữ liệu:** MongoDB 7.0 Community Edition (NoSQL Database).
  - **Tích hợp dịch vụ hàng không:** AirLabs Flight Schedule REST API.
  - **Môi trường triển khai:** Docker & Docker Compose đa dịch vụ (Backend, Frontend Nginx, MongoDB).
