## 3. BẢNG YÊU CẦU PHI CHỨC NĂNG (NON-FUNCTIONAL REQUIREMENTS - NFR)

| Mã NFR | Tiêu chí kỹ thuật | Đặc tả yêu cầu chi tiết | Giải pháp & Công nghệ thực thi |
| :---: | :--- | :--- | :--- |
| **NFR-01** | **Bảo mật & Phân quyền (Security & RBAC)** | - Xác thực bằng JSON Web Token (JWT) có thời hạn hết hạn an toàn.<br>- Mã hóa mật khẩu người dùng một chiều bằng thư viện Bcrypt (Salt rounds = 10).<br>- Phân quyền người dùng theo 4 cấp độ: `SUPER_ADMIN`, `ADMIN`, `CLERK`, `CUSTOMER`.<br>- **Bảo vệ tuyệt đối SUPER_ADMIN:** Không thể xóa tài khoản `superadmin` và không thể tạo thêm bất kỳ tài khoản nào mang quyền `SUPER_ADMIN`.<br>- Kiểm soát quyền sở hữu vé (`assertOwnership`): Khách hàng chỉ được phép xem và thao tác trên vé của chính mình. | - `AuthGuard`, `RolesGuard`<br>- `RolesDecorator` (`@Roles(...)`)<br>- `UsersService.create()`, `update()`, `delete()`<br>- JWT Bearer Interceptor phía Angular |
| **NFR-02** | **Đa ngôn ngữ (Internationalization - i18n)** | - Hỗ trợ song ngữ: Mặc định là **Tiếng Việt (VI)**, hỗ trợ chuyển đổi sang **Tiếng Anh (EN)**.<br>- Cơ chế chuyển đổi ngôn ngữ tức thời (Instant Switch) không cần tải lại toàn bộ trang web (Reload-free).<br>- Toàn bộ tiêu đề, nhãn biểu mẫu, thông báo lỗi, trạng thái vé đều được dịch chuẩn xác. | - `LanguageService` sử dụng Angular Signals (`currentLang`)<br>- Từ điển song ngữ JSON khép kín<br>- Pipe và Directive chuyển đổi chuỗi nhãn tự động |
| **NFR-03** | **Quy chuẩn Giao diện (GUI Standards)** | - Tuân thủ nghiêm ngặt tài liệu quy chuẩn `GUI_Standards_Document.md`.<br>- Bộ màu nhận diện Hàng không cao cấp: Xanh Navy Hàng hải (`#0A2540`) và Vàng Hoàng Gia (`#D4AF37`).<br>- Typography chuẩn: Phông chữ `Inter` (Google Fonts) hỗ trợ tiếng Việt tối ưu.<br>- Toàn bộ nút hành động đều có dạng **viên thuốc (`rounded-full`)** kèm hiệu ứng nâng đổ bóng (`shadow-md hover:-translate-y-0.5`).<br>- **100% Vector SVG:** Sử dụng thư viện `lucide-angular`, tuyệt đối không dùng Emoji trên giao diện. | - Tailwind CSS v3<br>- `IconComponent` (`shared/components/icon`)<br>- `SeatMapModalComponent` mô phỏng thân máy bay A321 |
| **NFR-04** | **Đóng gói & Triển khai (DevOps & Docker)** | - Đóng gói toàn bộ hệ thống bằng Docker và Docker Compose.<br>- Multi-stage Build cho Backend (NestJS dist build nhẹ) và Frontend (Build Angular và phục vụ qua Nginx Alpine).<br>- Khởi động toàn bộ CSDL MongoDB, Backend API và Frontend Web chỉ bằng một câu lệnh duy nhất: `docker compose up --build`. | - `docker-compose.yml`<br>- `backend/Dockerfile`<br>- `frontend/Dockerfile`<br>- `frontend/nginx.conf` |
| **NFR-05** | **Hiệu năng & Toàn vẹn Dữ liệu (Performance & Concurrency)** | - Thời gian phản hồi API tra cứu chuyến bay trung bình < 300ms.<br>- Đảm bảo tính nhất quán dữ liệu kho vé (No Overbooking): Sử dụng toán tử cập nhật nguyên tử của MongoDB để khóa ghế khi nhiều người cùng đặt vé.<br>- Đánh chỉ mục (Index) trên các trường tìm kiếm trọng yếu: `flight_number`, `departure_date`, `origin_iata`, `dest_iata`, `pnr_code`. | - Mongoose Schema Indexes<br>- MongoDB Atomic `$inc` & `$elemMatch`<br>- Standalone Angular Components lazy loading |
